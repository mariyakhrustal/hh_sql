# Сборщик вакансий
### Описание проекта:
Проект `Сборщик вакансий` взаимодействует с API HeadHunter, получает информацию о компаниях и вакансиях, 
проектирует таблицы в базе данных PostgreSQL и сохраняет полученные данные в созданные таблицы.
Этот проект разработан с использованием принципов **объектно-ориентированного программирования** (ООП).
## Установка
* Клонируйте репозиторий:
```
git clone git@github.com:mariyakhrustal/hh_sql.git
```
* Установите зависимости:
```
pip install -r requirements.txt
```
## Использование
1. Перейдите в модуль main.py, который находится в корне проекта.
2. Запустите функцию main(). Пример:
```
# Код для запуска программы
if __name__ == "__main__":
    main()
```
Или же через команду: `python main.py`
### Файл конфигурации`db_sample.ini`
#### Описание:
Файл `db_sample.ini` — это пример конфигурационного файла для приложения, который содержит список переменных окружения, необходимых для его корректной работы. 
Этот файл служит шаблоном и не должен использоваться напрямую для запуска приложения.
#### Как использовать
Переименуйте данный файл, например в `database.ini`.
Добавьте файл в `.gitignore`, чтобы избежать его случайного коммита в репозиторий!
Файл `database.ini` используется для хранения конфигурации подключения к базе данных PostgreSQL, которая необходима для работы проекта. 
В этом файле указаны все параметры, необходимые для настройки подключения к базе данных, такие как имя пользователя, пароль, хост и порт.
#### Пример содержимого `db_sample.ini`:
```
[postgresql]
host=localhost
user=your_user
password=your_password
port=5432
```
### Файл `config.py`
Данный файл расположен в пакете `src` в корне проекта. Модуль содержит функцию для чтения конфигурационного файла 
`database.ini` и получения параметров подключения к базе данных.
## Логирование 
Проект использует логирование для отслеживания действий с API и базы данных. Логи записываются в директорию logs,
которая будет создана автоматически в корне проекта.
